# v0.5.1 — Speed card + same-task benchmark

## Added

- Speed card assets in `docs/assets/`.
- Same-task pilot: raw OpenCode vs SCTG on multiply, bugfix, refactor, and
  security tasks.
- Machine-readable results in `docs/benchmarks/results.json`.

## Finding

On these small tasks, SCTG added 25–97% wall-clock overhead (overall median
+55.4%) while both arms passed visible and hidden tests. SCTG's value was the
auditable card/submission/gate/ledger artifacts, not raw latency.
