# Case studies

Three public case studies, each focused on a different control problem:

1. [Ten cards, one transaction layer](01-ten-card-shadow-pilot.md)  
   The transaction layer runs end to end — and a gate-green run still contains a
   semantic defect.

2. [From PARTIAL to PASS](02-stage-2-governance.md)  
   A historical PARTIAL is preserved, remediated, and re-audited with evidence
   instead of being rewritten.

3. [Lite, adapter, and two seats](03-stage-2.5-lite-multi-seat.md)  
   A Lite pilot, an independent join, and a real CLI alignment pass show why
   orchestration shape matters more than raw seat count.

These are rewritten summaries, not raw internal run logs. Metrics are retained;
paths, seat names, transcripts, tokens, and personal data are not.
