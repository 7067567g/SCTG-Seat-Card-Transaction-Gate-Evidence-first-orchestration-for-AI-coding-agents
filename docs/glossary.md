# Glossary

| Term | Meaning |
|---|---|
| Task Card | Scoped instruction and declared write scope |
| Seat | Single-line executor; one active card at a time |
| Submission | What the seat did, with evidence and commands |
| Gate | Deterministic check over a submission |
| GateResult | Structured PASS/FAIL/SKIP result |
| Decision Request | Proposal requiring independent approval |
| Decision Record | Approved/rejected object with scope, expiry, rollback |
| MAIN | Independent approval authority |
| Ledger | Append-only event/acceptance history |
| Shadow | Observe-only mode |
| Lite | Gate participates; host keeps fallback |
| Full | SCTG drives the main flow; not validated here |
| PARTIAL | Audit result with unresolved gaps; not a pass |
